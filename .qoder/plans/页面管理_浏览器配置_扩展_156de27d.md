# 页面管理浏览器配置扩展

## 已确认的范围
- 配置按网站独立保存，同一网站实例内的标签共用启动配置。
- 包含移动端模拟、自定义 UA、页面级常用配置，以及代理、无头模式、忽略证书错误、slowMo。
- HTTP/HTTPS 代理支持账号密码；SOCKS5 仅支持无认证。
- 保存不刷新、不关闭运行中的页面；停止并重新启动后生效，期间显示“待重启生效”。
- 不开放任意 Chrome 启动参数、浏览器路径、用户数据目录或调试端口。

## 页面管理交互
扩展 `src/renderer/src/features/sites/Sites.tsx`，将设备及高级表单拆为同目录组件；名称、网址和现有注入绑定功能保留。弹窗加宽并限制内容高度，使用分组折叠，设备配置默认展开。

| 分组 | 配置与默认行为 |
| --- | --- |
| 设备与 UA | 桌面默认、Android 手机（Pixel 5）、iPhone 13、iPad、自定义；预设填充 UA、视口、DPR、移动模式、触摸和横竖屏，之后允许手工调整 |
| 自定义 UA | 多行编辑框，实际值不得含换行或控制字符；手动值覆盖预设 UA，支持恢复预设；高级项支持 navigator.platform 和结构化 UA Client Hints 元数据 |
| 视口 | 宽高 240～3840 CSS px，DPR 0.5～3；渲染总像素不超过 3200 万；横竖屏切换交换宽高并同步方向 |
| 页面行为 | JavaScript、缓存默认开启；语言、时区默认跟随浏览器；定位默认关闭，开启后填写经纬度和精度；网站导航超时可选 10～120 秒，留空沿用项目设置 |
| 额外请求头 | 可增删的名称/值表格；最多 50 项，每值最多 8 KiB、总量最多 32 KiB；拒绝重复名称、控制字符及受管理字段 |
| 启动与网络 | headless 默认 true；acceptInsecureCerts 默认 false；slowMo 默认 0，范围 0～500 ms；代理地址、绕过列表、认证开关和账号密码 |

- 预设只改设备相关项，不覆盖代理、请求头、定位或注入配置；手动修改设备字段后标记“自定义”。桌面恢复为现有 1280×800、DPR=1、非移动、无触摸。
- Android 预设使用随附 Chrome 的实际版本构造 UA/Client Hints；iOS 预设使用 Puppeteer 的设备描述，不发送虚假的 Chromium Client Hints。自定义 UA 不猜测任意字符串的系统信息，允许用户显式配置元数据。
- 明确说明：设备模拟仍使用 Chrome，不等于真实 iOS/Safari，也不保证所有网站的设备识别或风控结果。
- 语言同时影响 Accept-Language、navigator.language/languages 与 Intl；IANA 时区经校验后应用。
- 定位仅对网站配置 URL 的 origin 授予权限，不向其他域名自动授予定位权限。
- 请求头属于普通本地配置，界面提示不要填入密钥；禁止 Cookie、Authorization、Proxy-Authorization、Host、Content-Length、连接级字段，以及由 UA/语言配置管理的 User-Agent、Accept-Language、Sec-CH-UA*。登录信息继续通过 Cookie 管理维护。
- 非无头模式提示将打开独立 Chrome 窗口；忽略证书错误显示安全警告，默认关闭。
- 列表增加设备/视口摘要和独立的配置待重启标记；工作台状态栏显示当前实际运行尺寸，而不是尚未生效的草稿尺寸。

## 数据模型与生效规则
- 新增 `src/shared/browser-options.ts`，集中定义配置 schema、默认值、设备描述、规范化和摘要逻辑；`src/shared/model.ts` 的网站模型新增 `browserOptions`。
- 旧配置缺少该字段时补齐桌面默认值，沿用 schemaVersion=1 的兼容扩展方式，不修改已有网站 ID、浏览器目录、Cookie 或注入绑定。
- IPC/MCP 保存请求中，省略 `browserOptions` 表示保留原值；显式提交对象表示完整替换，`{}` 表示恢复默认。请求 schema 不提前补默认值，避免旧客户端修改名称时覆盖新配置。
- 在 `BrowserManager.start` 开始时读取一次完整网站快照。启动参数、页面初始化、代理凭据和后续新标签均使用此快照；运行中保存不能让新旧标签混用配置。
- 规范化配置及代理凭据引用参与指纹比较，生成 `browserOptionsPending`；仅改名称不触发，改回原配置可消除标记。指纹保留在主进程，不包含明文密码。
- 网站自定义导航超时随重启生效；未覆盖时继续沿用项目级导航超时的现有即时更新行为。

## 浏览器执行与代理认证
主要改动 `src/main/browser/manager.ts`，新增同目录配置应用模块，避免继续扩大管理器中的内联初始化逻辑。

- 使用 Puppeteer 25 已提供的 `setUserAgent` 对象接口、`setViewport`、`emulateLocale`、`emulateTimezone`、`setGeolocation`、`setJavaScriptEnabled`、`setCacheEnabled` 和 `setExtraHTTPHeaders`。
- 启动及主动新建空白标签先完成配置，再注入显式绑定的脚本，最后导航；关闭最后标签后补建的页面也走同一流程。
- 网页弹窗在现有目标接管流程中应用相同快照，不自动刷新或重放请求，避免破坏登录授权/POST 流程。与现有实现一致，弹窗接管前已经发出的首次请求不承诺追溯生效；后续导航使用完整配置，界面说明此边界。
- 初始化失败必须关闭失败标签、释放监听和会话；启动失败保留登录目录并返回不含敏感信息的错误。
- 启动配置映射至 `headless`、`acceptInsecureCerts`、`slowMo`，代理仅生成受校验的 `--proxy-server`、`--proxy-bypass-list` 参数；继续锁定回环调试地址、独立 profile 和下载限制。
- 代理 URL 仅接受 http/https/socks5 的主机及端口，不允许内嵌账号密码、查询或业务路径。代理不宣称覆盖所有 WebRTC/浏览器旁路流量。
- 在现有 `src/main/browser/interception.ts` 的同一个 Fetch 会话中增加 `authRequired` 处理，不调用会创建另一条认证拦截链的 `page.authenticate`。仅对匹配所配置代理的 Proxy challenge 提交凭据；源站认证不使用代理密码，同一请求重复认证失败后取消，停止时释放相关状态。
- 页面配置作为基础值先应用，可信注入脚本仍可显式覆盖；不改变注入必须由用户按网站绑定的规则。
- 行动和注入 Worker 的连接继承当前实例的 slowMo、证书策略和导航超时基础值，仍保持 `defaultViewport: null`，不重置移动视口。脚本自身的总执行超时与取消机制继续优先，slowMo 不自动延长任务预算。

### 代理凭据保存
- 复用 `Encryptor`、Electron `safeStorage` 和原子写入，在存储模块增加独立代理凭据 vault，不与 MCP 令牌共用密文文件。
- `site.save` 增加独立的凭据写入参数：省略保留、null 清除、对象替换。持久化网站配置仅存随机凭据引用；编辑界面显示“已保存”，不回填旧密码，提供替换和清除操作。
- 新凭据先加密写入新引用，再提交网站配置；配置提交失败清理新引用，不能覆盖仍被旧配置引用的凭据。保留当前配置、配置备份和运行快照引用的密文，其他无引用记录在安全清理时移除。
- 加密或解密失败明确报错，不降级为明文，也不静默切换为无认证连接。普通 snapshot、MCP 读取结果、日志、异常和启动参数均不得包含账号密码。
- 关闭代理或清除认证通过配置去掉引用；只清理网站登录态时保留代理配置，删除网站配置时清理不再被备份或运行实例引用的密文。

## 画面与输入适配
联动 `src/shared/coordinates.ts`、`src/main/browser/stream.ts`、`src/main/browser/input.ts`、`RemoteCanvas.tsx` 和工作台状态栏。

- 移除固定 1280×800 的绘制、流尺寸、滚动中心和坐标边界假设；默认尺寸常量仅作为默认值。
- 帧附带当前 CSS 可见区域及缩放信息，结合 CDP screencast 元数据/布局指标统一实时流和截图降级路径。Canvas 使用实际图像比例居中 contain，分别处理图像像素、DPR 与移动页面缩放，避免无 viewport meta 页面点击偏移。
- 根据实际帧对应的 CSS 区域映射输入；留白不接受点击，拖出画面仍可夹紧和释放。主进程在 IPC/MCP 两条入口按目标页面实际区域校验坐标，不能只扩大静态上限。
- 移动且开启触摸时，将主按钮点击/拖动映射为单指触摸；保留键盘、中文输入与滚轮操作。失焦、切标签、停止时释放触点；本次不增加双指缩放手势。
- 保持 generation/tab/sequence 的旧帧隔离和背压机制，帧确认协议仍只使用身份及序号字段。

## MCP 同步
修改 `src/main/mcp/tools.ts`，保持权限等级不变。
- `save_site` 支持同一套浏览器配置和只写代理凭据参数，使用共享校验，省略字段保留现有配置。
- `list_sites` 返回设备摘要、配置待重启状态和无敏感值的配置概况；`list_tabs` 返回当前可操作 CSS 区域。
- `get_settings` 将已有 viewport 明确描述为默认桌面尺寸，不再宣称所有页面固定该尺寸。
- click/scroll 的坐标以目标页 CSS 可见区域为准；scroll 未指定坐标时动态取中心。
- 截图工具返回图片并附带图像尺寸、CSS 区域及缩放说明，避免高 DPR 图片上的像素位置直接被当成 CSS 坐标。

## 验证计划
- 单元测试：旧配置补默认值、IPC/MCP 省略字段保留、预设与 UA 优先级、请求头/代理/时区/定位及数值校验、指纹与重启语义、代理凭据写入失败恢复和脱敏。
- 浏览器测试：本地测试站同时记录请求 UA/Client Hints/语言和页面 navigator、屏幕、DPR、触摸、Intl、定位；覆盖桌面、Android、iPhone、自定义 UA，以及 JavaScript/缓存/导航超时。
- 交互测试：竖屏、横屏、高 DPR、无 viewport meta、截图降级、点击/滚动/单指拖动/中文输入、MCP 动态中心和越界拒绝。
- 生命周期测试：运行中保存不影响已有及随后新建标签；重启后统一生效；弹窗、关闭最后标签、注入和任务执行继续正常；两网站配置互不影响。
- 使用本地代理夹具验证 HTTP、HTTPS CONNECT、代理认证成功/失败/重试限制、源站 401 不泄露代理凭据；证书错误默认拒绝、显式启用后可访问；无头与有头模式均验证启动和停止。
- 执行 `npm run typecheck`、`npm run lint`、`npm test`、`npm run test:e2e`，回归现有登录态、注入及任务编排用例。
